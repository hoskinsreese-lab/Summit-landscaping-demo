# Summit Outdoor Co. — Vexo Digital portfolio concept

A fictional landscaping company website built as a static, responsive demo. No real business or completed projects are represented.

## Features
- Responsive navigation
- Filterable project gallery
- Draggable before/after illustration
- Interactive sample estimate calculator
- Demo ZIP-code service-area checker
- Consultation request preview form (does NOT transmit or book appointments)

## Launch on GitHub Pages
1. Create a public GitHub repository (e.g., `summit-outdoor-demo`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Under Settings > Pages, choose Deploy from a branch, main, / (root).
4. Wait for deployment and visit the URL GitHub displays.

## Important notes
- Photos are loaded from Unsplash URLs. Internet access is needed for photos; the page has background-color fallbacks. For real clients, use client-provided assets with appropriate permission, saved locally in an `assets/` directory.
- The before/after comparison is a CSS illustration, not a real client project.
- The estimate amounts are fictional sample rates and must be replaced for a real business.
- The service area is an illustrative list of Helena-area ZIP codes, not an actual service commitment.
- The booking form only shows an on-screen demo confirmation. To make it real, integrate a provider such as Calendly or a secure form backend.
- No payment processing is included.
